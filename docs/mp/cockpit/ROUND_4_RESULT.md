# R4 结果与回写：一次玩家更新的角色路由

本轮 16 根 + ABI 复核 6 根（r4/r4b）。证据为同 SHA 的 C/ASM/JSON，最新 r4b 覆盖同名伪代码。
S=静态事实，H=语义推断，D=设计，O=待验证。未运行游戏。

## 查询 ABI 和时序

- S：187C80 为边沿查询，读取 device+40/+44，返回 AL。187A40 为 held 查询，读取 +38/+3C，返回 AL。
  +38/+3C 在 187390 开始时是上一采样状态，结束时已经被当前 held 覆盖；不能在整帧都称其为 previous。
- S：187390 产生 `pressed = held & (held ^ previous)`，写 +40/+44；+48/+4C 是带延迟/周期的 repeat。
  按钮组合绑定会用到其他 held 条件，不能用单个物理按钮位替代 action 查询。
- S：187EC0 的值来自 device 的字节压力值及常量乘法；**真实结果在 XMM0，是 float**。
  187F3B/187F3F 转换/乘法、18807A 出口和 111F72 等 caller 保存 XMM0 交叉证实。
  旧自动伪代码将它恢复成整数是错误的；本轮 ApplyCockpitContracts.java 修正存储签名后重新导出。
  DL=逻辑槽，R8B=action；187EC0/187C80 的 RCX 并不是可靠的 context 参数（使用全局 32C8F0），
  而 187A40 的 RCX 确实读取映射 context。不可把三者 ABI 混用。
- S：201DC0 先 188A80 原始输入规范化，再 188180 更新设备，绑定逻辑槽 0/1，最后处理反馈。
  它同时写多个全局映射表；直接改设备对象或全局 P2 槽会影响菜单等消费者。

| 0C | held 104D45，edge 104ECC；1031B0 内也查询 | 普通/特殊发射相关状态，1040C0 调 141200 | P2 发射，保留原生接受判定 |
| 02 | edge 104AB1 | 切换 P+2098 分支，重置/更新 P+1E38 武器目标状态 | H：武器模式切换，P2 候选 |
| 11..18 | analog 10F600 | 四组差值写 flight+220/224/228/22C，随后 12AA30 | P1 飞行；各轴物理命名需校准 |
| 24 | held 10F600 | 进入替代飞控/辅助分支 | P1；精确用户语义 O |
| 19/1B，1D/1F | analog 111D40 | 两对差值进入相机求解 | P1 原生相机；P2 私有相机用自定义输入 |
| 22 | edge 1042C2 | 写 P+2094，连带 cockpit/HUD 分支 | 只属 P1 原生视图，不共享给 P2 |
| 0E | held/analog 111D40；held 105A2B | 相机目标相关状态及 P+20A6/1EEE | 共享语义动作须由 P2 仲裁；P1 相机侧使用需解耦 |
| 0F/26 | edge/held 1040C0 | 写 P+1EEE、20A7/20A8 等目标状态 | H：目标操作候选，未以按钮名称放行 |
| 10 | edge 105B5E → 0B7B40 | 轮转 HUD 内部 H+3C9 状态（条件成立时） | 共享 HUD 操作；具体名称 O |
| 04/06/0A/08 | edge → 0BBC50，0BBE00 | 共享 manager+68/+69 命令/菜单状态 | 独立控制面；不按“其他武器”自动开放 |

0D 的机炮路径与 0C 的其他武器路径已从发射调用和资源递减区别开；**0E 跨相机和目标系统复用**，
这是本轮发现的重要隔离点。不能采用“所有非飞行 action 都交 P2”的全局掩码。
13ACE0/141200 导出供审计发射的副作用，未据此声称其 ABI 已可从 Rust 直接调用。

## 路由契约与 R5 回写

D：网络线程只产生 `(session_epoch, sequence, role, held/analog, camera_delta)`；主线程唯一 Tick 冻结输入快照。
在 gameplay 的 P0 消费作用域以 action+consumer 路由，飞行和机炮用 P1，武器用 P2；相机消费者须独立于目标动作。
沿用原生合法条件和发射路径，不直接调用发射函数。查询 hook 只能在明确作用域命中，不能全局返回假值。

边沿由“已接受的连续角色状态”产生一次，重复/乱序包不重复发射；超时、退出 gameplay、换场景清零 held 和 pending edge。
重连必须新 epoch 并先接受中性基线。未知 action 默认不远程开放，列入校准。
单个 Tick 多个消费者查询同一 edge 应得到一致快照，不能在第一次 query 后销毁（原生可能多处查询同一 action）。

P2 相机仅更新私有 yaw/pitch/Camera，不写 P+2094，不再次运行 111D40，也不移动 OS 鼠标。
共用飞机、弹药、目标和 HUD 的生产者保持一次。R5 核验渲染包、分屏矩形、GPU 提交及生命周期；
运行前仍须校准未知动作语义、输入冻结与 native update 的实际时序，当前未声称网络接入完成。
