# R3 计划：共享 HUD 状态与机头固定的显示几何

依据 R2，第二视图不再重复调用有输入/RNG副作用的玩家相机解算。
本轮从 108620→0AE510 追踪 HUD 状态、投影相机和图元分类。

初始根：108620、0AE510、109DC0、10A2E0、156D10、157F40、1580C0、158D00、0ADC80。
根据 HUD 根实际 callee 和投影读写追加根，特别检查 P+10B0/1270 是否被硬编码读取。

输出要求：

1. 同一弹药/锁定/目标/飞行 HUD 状态的生产与消费位置。
2. reticle/姿态图元、世界目标标记、二维文字/雷达/边框的投影与布局差异。
3. HUD 生成是否推进时钟/缓存/计数，哪些状态不能因第二视图重复消费。
4. 整 HUD 纹理平面重投影与逐图元重投影的可行性、正确性差异。
5. 精确的“机头参考方向不随摄像机旋转”实现接点，或明确尚缺的消费者证据。

结果回写 R4 的共享武器状态/摄像机输入边界，及 R5 的两视图绘制顺序与状态恢复。
