## 分时回写契约

采样 N 进入返回边时，游戏线程先封存已经发布的 Bridge 结果，再复制当前 P2 原始按钮值并排队。线程只选取同一代、截止点前已发布、来源序号小于 N 且仍在有效期内的结果。即使工作线程很快，N 的输入最早也在 N+1 提交。工作线程只处理值，游戏线程在同一返回边一次提交。原生读者的边沿由原生快照生成。

结果按来源顺序交付。相邻相同电平可合并，按下和松开之间的跃迁必须保留。每次采样至多提交一个可见跃迁，原生重复由 `187390` 生成。绑定、设备身份、活动战斗代或授权状态变化时取消旧代。重复、过期、队列溢出或跨代结果一律丢弃。活动窗口内若 Bridge 尚无有效结果，移交的位保持零，直到得到新一代有效输入。进入有效代前要求移交位中立，避免把激活前已按住的键当作新边沿。

`188ABD` 只能利用截至该时刻的模式和身份信号。切场景当帧可能在快照发布后才改变更新路径。需要记录活动战斗入口和原生消费，以实测确定生命周期信号与窗口守卫；应用序号本身只证明写回。
