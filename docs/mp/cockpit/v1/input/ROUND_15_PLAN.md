# R15 计划：中立、松键与原生挂起状态

沿 `1040C0` 和 `1031B0` 跟踪 0E、26 的 held→released 路径，以及 0C pressed 被接受后进入的待发路径。重新导出目标、战斗循环、原生镜头和快照函数，搜索 `+1EEE`、`+20A6`、`+20A8`、`+20BE` 和 `+20C0` 的操作数候选，核对写入者和生命周期路径。操作数匹配只用于定位，随后核对基址和调用关系。

验收要求是列出清空 Bridge 的效果、可能发生的原生松键副作用、已经受理命令的范围，以及初始掩码和扩展掩码分别需要的运行验收。以原生设备层入口和一次回写为边界。

操作数扫描将 `102AB0` 和 `0C4660` 列为候选。补导两个函数，分别核对所用对象、清理覆盖范围和调用条件。补导 `13D140`，核对 `1031B0` 的后续发射路径。
