# R10 计划：活动模拟作用域内的角色输入

以 R6 的 0CF865 活动调用、0CF038 暂停拒绝和 R9 的一次语义生产为约束。重新导出 1040C0、1031B0、10F600、111D40、187A40、187C80、187EC0、187390、188180、188A80、201DC0、0BBC50、0BBE00、13ACE0、141200。用汇编逐一核对动作号、返回存储和语义消费者，区分物理设备、逻辑槽和角色。找出可作用域路由的最小 callsite 集与应保持原生的调用。补冻结时序、重复和暂停恢复，以及 V1 可执行的验收顺序。

首批发现 0E/26 有原生短按释放副作用，且 1040C0 有活动作用域以外的其他调用者。补追 0C11C0、10B000、0C1030、106F30、0D03A0、1B8C40、13D140，并核对逻辑槽的重新绑定与取消语义。退出时不得把持有中的动作伪装成普通释放。
