# ACZ 共享座舱 V1 定版

定版日期 2026-11-03，依据 mp 的 1f8bdcf。状态为范围、接口及验收已定版，原生接点须经对应验证后放行。

本地 V1 由同一个 ACZ 进程承载一个战役世界和一架可控飞机。P1 驾驶并控制机炮，P2 控制其余武器及目标选择。两人有独立观察输入，首版以同一个机体上的眼点为原点，仅旋转视向。两路画面在同一个窗口内合成，P2 矩形用输出像素配置。远程输入、视频、独立窗口和座位位移归后续版本。

HUD 的弹药、武器、目标和锁定只来自该飞机。同一画面批次使用同一份状态和一台固定在机头方向的参考相机。两路画面分别将该参考层投影到各自视角，超出有效投影区域的图元裁掉。参考层的中间表示为有序 HUD 批次，合成等价时可压成透明纹理。机头图元随飞机转向，转头时允许移出屏幕。世界标记保留同原点的射线关系。合成布局和转头均不改模拟状态。

| 模块 | 输入和输出 | 放行条件 |
| --- | --- | --- |
| M0 场景门控 | 生命周期、模拟步和设备事件 → 场景租约及帧键 | 实测关卡进入、重试、暂停、结果、播片和 resize 后，旧键不能进入新帧 |
| M2 相机 | 机体眼点、机头基准、两人视向 → 两台视图相机及 HUD 相机 | 原生零偏移数值一致，轴向与裁剪可测，转 P2 时 P1 状态不变 |
| M3 视图产包 | 两份相机、帧键、列表与目标租约 → 两份场景输出 | 原生模拟调用计数与基线一致，视图间没有缓存、目标、清屏或深度污染 |
| M4 HUD | 共享语义状态、参考相机、包来源 → 参考层和覆盖范围 | 状态生产与 HUD 产包各执行一次，图元完整、透明混合正确，两视图状态一致 |
| M1 分权 | 两路设备记录、角色租约 → 原生归一化前的合成按钮字 | 机炮/其余武器交叉测试、短按/长按、暂停恢复、断开归零全部通过 |
| M5 合成 | 两场景、HUD、像素矩形 → 一帧原生呈现 | 视图布局变更独立于投影和模拟，资源交接符合 fence，单次 Present |

按 M0/M2 → M3 → M4 → M1 → M5 接入。M0/M2 先做只读基线。其余写入分别由功能开关和已验证的原生前置条件保护。输入在游戏线程的设备采样返回边替换。Bridge 异步传值，游戏线程一次回写，由原生生成快照。相机观察每个渲染帧可采样一次。暂停、模式退出、失败及设备重建时失效旧租约，输入交接遵循中立及生命周期条件。具体见[设备输入分流](input/README.md)。

FrameKey 由 scene_epoch、device_epoch、tick_id、render_frame_id 组成。暂停或重复渲染时 tick_id 可以不变，同一渲染帧两路输出和 HUD 必须同键。SurfaceLease 同时携带 GPU queue、fence 值和资源状态。原生指针只在 native adapter 作用域内使用。

最终验收使用完整游戏的同一存档和固定任务，以原生基线为对照。分别记录世界更新、两台相机矩阵、HUD 来源与 draw 数量、权限拒绝、资源代次和 Present。功能开关关闭后复测基线。具体前置实验以原有 G0–G7 和本次五轮回写为准。阶段未通过即停在对应模块。

R6–R10 的证据与放行决定见[定版研究索引](README.md)和[接入与运行验收](INTEGRATION.md)。
