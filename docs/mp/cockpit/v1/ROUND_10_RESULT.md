# R10 回写：分权表、取消语义和原生入口

本轮导出 r10/r10b，并用 R6 全局直接调用索引反查作用域。以下地址均为 RVA，动作编号是十六进制。

## 唯一输入作用域

201DC0 先经过 188A80 与 188180，再把 input manager+140/+148 的逻辑设备指针映射进 32C8F0 的两个槽，并写有效性字节 +2B6/+2B7。188180 每次采样会按类别、优先级和回退条件重新选槽。V1 的 P1/P2 角色绑定独立持有设备身份和代次。槽 1 可能为空或重新绑定，角色权限须单独验证。

187A40 使用 RCX 映射上下文并回 AL。187C80 使用全局映射并回 AL，187EC0 使用全局映射并回 XMM0 float。共同输入 DL=逻辑槽，R8B=action。模拟量字节乘 PE 中 2D1E98 的约 1/255。组合映射在 187EC0 内也可能调用 187A40，因此路由必须同时验证返回地址/消费者和活动作用域。187390 先比较旧 held，再写 pressed +40/+44、repeat +48/+4C，最终更新 held +38/+3C。V1 在设备采样完成后获取值，在活动模拟调用前冻结角色快照。

1040C0 在当前直接调用索引有 0CF038、0CF865、0D4FF4、1B8FC2 四处入口。仅 0CF865 可作为 V1 活动调用候选，仍需 M0 校验场景和控制位。0D03A0→106F30 另有 10707D 的 0x10 查询和 1070AC 的 HUD 更新，111D40 也有多个父调用。按已观测的 baseline 路径保留次数，双视图不得新增调用。间接调用需 HIL 观察。

## 松手与取消的差异

105A2B 的 0E held 为假时，若 P+20A6 非零且小于阈值，105A57 设置 P+1EEE bit0，再由 105A5E 清计数。26 held 为假时，105ACA–105B34 根据持有计数和目标旗标清 bit7/bit6，或设置 bit6 与 P+20A7。10B000 随后消费这些字段。直接返回假值会触发上述正常释放逻辑，即使插件端没有生成 edge。

M1 冻结快照区分 Pressed、Held、Released、Cancelled。同一 role_epoch 内有效的下降沿可产生 Released。断开、焦点丢失、暂停、失效帧产生 Cancelled，阻断 0E/26 的释放状态写入并使对应计数回到原生基线。具体实现须先用 HIL 证明分支屏蔽与清计数的安全边界，在此之前 0E/26 保持未放行。恢复采用新 role_epoch 和中性采样。输入线程只发布值快照，武器判定留在原生模拟。

## V1 验收补充

- 同一活动步对 0C 重复查询，记录 query 结果、真正发射和弹量减量。快速按下/松开仍保留一次有效 edge。机炮用 held 验证连续控制。
- 分别让 P1 按导弹、P2 按飞控与机炮，原生消费者都不得收到越权动作。换绑两个设备、拔线、失焦和暂停期间验证取消，恢复前要求中性。
- 对 0E/26 做短按释放、长按释放、持有时取消三组实验，逐帧比较 P+20A6/20A8/1EEE 和 target_id。相机的 0E 分支只看 P1。
- 在活动、暂停、特殊任务阶段逐帧核对 1040C0 调用点与 0B7B40 的 baseline。只有匹配的活动作用域开放写入。
