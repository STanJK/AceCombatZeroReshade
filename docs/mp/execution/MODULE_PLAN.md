# 分模块实行书

本轮实现可运行的 Rust 基础层、跨模块网络演练、构建校验和原生只读观测适配。
原生 P2 构造、飞行写入、完整武器/任务/存档行为仍依赖 RE05–RE17 的实机闭环；
不能用模型实现冒充游戏适配成功。后续原生写入的端口和拒绝行为也纳入本轮接口。

| 顺序 / 模块 | 标准输入、输出、责任 | 单元验收 | 对外依赖 |
| --- | --- | --- | --- |
| E01 `contracts` | 槽位、角色、非零世代/实体 ID、Tick/序列、有限数值的网络姿态、标准错误 | 非法槽、世代耗尽、序列回绕/半区、NaN/Inf、ID 世代检查 | std |
| E02 `protocol` | 40 字节头；显式小端；输入、协商、完整快照分块、权威事件；精确长度/枚举/上限 | Golden 字节、每个截断、尾部、错误版本/标志、越界、非有限值、非法实体 | contracts |
| E03 `session` | 会话阶段、角色权限、双方就绪、暂停/结果/重试；输入窗口/槽归属/边沿/超时 | 非主机推进、未就绪开始、旧世代、重复输入、乱序/回绕、过期输入归零 | contracts |
| E04 `replication` | 稳定实体表；完整分块原子组装；单调事件/去重；主机结果与存档权限 | 缺块不应用、冲突重复、旧快照、实体复用、伤害重复、事件缺口与旧世代 | contracts, protocol |
| E05 `transport` | 有界 TCP 实验通道；接管连接时统一阻塞模式；PSK 挑战/HMAC 相互认证；随机 nonce；会话绑定；限长/超时/错误后关闭 | 双向回环、非阻塞 socket 接管、错误密钥/角色、截断帧、超大长度、超时、认证前禁止包 | protocol, contracts, crypto |
| E06 `game` | 只读 MemoryReader；构建/PE/地址和证据指纹；模式生命周期、线程、玩家/Actor 读取；原生写入能力门槛 | 错误构建、地址溢出/读取失败、未就绪、错误线程、leave 后禁读、非法数量/选择器 | contracts, sha2 |
| E07 `trace` | 固定容量非等待入队；明确丢弃计数；工作线程/外部端写 JSONL；空闲刷新；来源和阶段标记 | 容量溢出、停止后发送、记录完整性、退出记录可见、写失败可见 | contracts, game |
| E08 `runtime` | ReShade API 20 add-on 加载；薄入口；SHA/指纹门槛；原生观测 Hook；永不从网络/渲染线程调用游戏写函数 | 初始化失败回滚（可测试状态机）、Windows 构建、导出；游戏 HIL 单列 | game, trace, Windows, MinHook |
| E09 `cli` | doctor 校验 EXE；实际回环/双进程演练；注入部署包和诊断命令 | 跨模块场景：协商→就绪→输入→快照→伤害→结果→重试→拒绝旧世代 | 以上可移植模块 |

每个模块完成后：运行其测试，检查 Cargo 依赖和公开接口、错误路径、容量、所有权，
再在 [审计日志](AUDIT_LOG.md) 登记证据和未完成项。接口变更必须修改消费者并跑受影响模块。
全量通过后执行 fmt、clippy、workspace 测试、跨模块演练、Windows 目标验证和档案校验。

## 原生后续施工模块

N01 本地战役 P2：任务定义扩展、两套资源、显式玩家 Actor 绑定，保留剧情单位。
N02 飞行/实体：积分器全部状态、创建释放/复用与内容 ID 映射。
N03 战斗：三条发射根到命中/消失/伤害的完整生命周期。
N04 任务/存档：主机唯一脚本事件、加载屏障、一次结算和保存，客机写盘抑制。
N05 在线发布：低延迟多通道传输、Internet 穿透/中继、完整路线验收。

N01–N05 不以空函数、常量成功返回或模型测试标记通过。当前能实现的安全边界会明确
拒绝未证明的游戏写入，而不是猜测参数调用。M0 只有游戏内追踪通过后才可放行。
